#  GMP CTL Component 文件夹新手指南

你好！欢迎来到电机控制的世界。作为一个刚接触这一领域的大学生，面对这一大堆代码和陌生的术语，感到迷茫是非常正常的。

这个文档专门为你准备，旨在用最通俗的语言带你理解 `ctl/component` 文件夹都在做什么，以及如何利用它来搭建你的第一个电机控制系统。

## 1. 写在前面：核心名词通俗解释

在深入代码之前，我们先扫清一些“拦路虎”。电机控制里有很多缩写，其实原理并不复杂。

### 基础概念
*   **MCU (Microcontroller Unit)**: 微控制器，也就是你的“芯片”或“单片机”（如 STM32, TI C2000）。它是大脑，负责运算和发号施令。
*   **ADC (Analog-to-Digital Converter)**: 模数转换器。芯片的“眼睛”。现实世界的电压、电流是连续的模拟信号，芯片只认识 0 和 1。ADC 把模拟电压变成数字，让芯片能读懂。
*   **PWM (Pulse Width Modulation)**: 脉宽调制。芯片的“手”。芯片输出只有高电平（如 3.3V）和低电平（0V）。为了输出 1.65V 怎么办？芯片就快速地不停开关，开一半时间关一半时间，平均下来就是 1.65V。这就叫 PWM。
*   **ISR (Interrupt Service Routine)**: 中断服务程序。芯片的“反射神经”。当一个定时器时间到了（比如每 0.0001秒一次），芯片会立刻停下手中的活，去执行这段代码。电机控制的核心算法通常都在这里面。

### 电机控制黑话
*   **PMSM (Permanent Magnet Synchronous Motor)**: 永磁同步电机。现在最火的电机（特斯拉、大疆都在用）。转子上贴了磁铁，定子上有线圈。
*   **FOC (Field-Oriented Control)**: 磁场定向控制。一种让电机转得极度平丝滑、安静且高效的控制算法。
    *   *通俗比喻*：以前控制电机像是在后面推它，不管它转到哪都傻傻地推。FOC 像是你在推磨，你始终顺着磨盘切线的方向推，力气一点不浪费。
*   **SVPWM (Space Vector PWM)**: 空间矢量脉宽调制。FOC 算法用来生成 PWM 波形的一种高级方法。它能最大限度地利用电压，让电机转得更快。
*   **PID (Proportional-Integral-Derivative)**: 比例-积分-微分控制器。自动控制界的“万金油”。
    *   *场景*：你要把水温加热到 50度。
    *   **P (比例)**: 现在的温度离 50度差得越远，火就开得越大。
    *   **I (积分)**: 如果温度一直卡在 49度上不去，I 会慢慢积攒怒气，把火开大，直到把你推到 50度。
    *   **D (微分)**: 如果温度升得太快，眼看要冲过头了，D 会提前减小火势，防止过冲。
*   **Clarke / Park 变换**: 坐标变换。
    *   电机是三相的（三根线 UVW），电流是正弦波，很难算。
    *   **Clarke**: 把 3 系坐标（ABC）变成 2 系静止坐标（αβ）。
    *   **Park**: 把 2 系静止坐标（αβ）变成 2 系旋转坐标（dq）。
    *   *结果*：做完变换后，原本正弦波动的交流电流，在 dq 坐标系下变成了**直流电**（直直的一条线）。这样 PID 控制器就可以像控制直流电机一样容易地控制它了！

## 2. Component 文件夹是做什么的？

**一句话总结：它是一个巨大的“乐高积木箱”。**

在没有这个文件夹之前，如果你想控制一个电机，你需要把“读ADC寄存器”、“算PID”、“操作PWM寄存器”这些代码全部杂糅在一起。如果你换了个芯片（从 TI 换到 STM32），代码得重写；如果你换了个电机，代码得重改。

`ctl/component` 把这些功能拆解成了一个个独立的、标准的**组件（Component）**。

### 这里面主要装了什么积木？

请打开文件夹对照着看：

1.  **`interface/` (接口积木)**:
    *   这是最重要的“转接头”。
    *   它定义了什么是“电压输入”，什么是“PWM输出”，但它**不包含**具体的芯片代码。
    *   **作用**：你的控制算法只跟这个接口说话。比如算法说“我要 50% 的占空比”，它就告诉接口。至于怎么操作寄存器去实现 50%，那是底层驱动的事，算法不管。

2.  **`intrinsic/` (基础数学积木)**:
    *   这里面是所有控制系统的基石。
    *   **PID 控制器**：不需要自己写公式，直接拿来用。
    *   **滤波器**：信号有噪声？拿个滤波器组件串进去。
    *   **信号发生器**：想要一个正弦波？这里有现成的。

3.  **`motor_control/` (电机专属积木)**:
    *   这是专门为电机定制的高级积木。
    *   **编码器处理**：处理位置传感器信号。
    *   **SVPWM**：生成马鞍波驱动电机。
    *   **FOC核心**：电流环、速度环的封装。

4.  **`digital_power/` (数字电源积木)**:
    *   如果你做的是开关电源（Buck/Boost电路），用这里的积木。原理和电机控制其实很像（都是PWM控制电感电流）。

5.  **`hardware_preset/` (参数预设卡)**:
    *   **小白神器**。
    *   这里有很多 `.h` 头文件，里面写好了各种市面上常见的电机（如大疆的电机）和开发板的参数（电阻、电感、极对数）。
    *   **作用**：你不需要拿着万用表去测电机参数，直接 `#include` 对应的头文件，参数就自动配好了。

## 3. 如何利用这个文件夹进行开发？

作为初学者，你的开发流程不再是“从零写代码”，而是“搭积木”。

### 第一步：挑选硬件参数卡 (`hardware_preset`)
去 `hardware_preset` 里找有没有你用的电机或板子。
*   如果有，直接在你的代码里 `#include` 进来。
*   如果没有，随便复制一个现有的文件，改名为你的电机型号，然后把里面的电阻 `Rs`、电感 `Lq` 改成你自己的。

### 第二步：初始化积木 (Init)
在你的主程序（`main.c`）初始化阶段，把你要用的组件领出来，告诉它们参数。

```c
// 伪代码示例

// 1. 初始化 PWM 接口积木
ctl_init_pwm_channel(&pwm_u, ...); 

// 2. 初始化 PID 积木 (用于电流控制)
ctl_init_continuous_pid(&pid_id, kp, ki, ...);

// 3. 初始化 SVPWM 积木
ctl_init_svpwm_modulator(&svpwm, ...);
```

### 第三步：搭建控制循环 (Step)
这是最关键的一步。在你的**中断服务函数 (ISR)** 里，把积木连起来。

想象一下数据流：**读取 -> 计算 -> 输出**。

```c
// 中断服务函数 (每 100微秒 运行一次)
void Motor_ISR() {
    // === 1. 读取 (Input) ===
    // 用 ADC 积木读取现在的电流
    ctl_step_adc_channel(&adc_current_a);
    
    // === 2. 计算 (Process) ===
    // 算一下 Clark 和 Park 变换 (可能有专门的积木，或者手写)
    // ...
    
    // 运行 PID 积木：算出我们需要多大的电压来修正电流误差
    // 目标是 2A，实际是 1A，PID 算出来需要加电压
    float v_d = ctl_step_continuous_pid(&pid_id, target_current - actual_current);
    
    // === 3. 输出 (Output) ===
    // 把 PID 算出来的电压给 SVPWM 积木
    // SVPWM 会算出三个占空比
    ctl_step_svpwm_modulator(&svpwm, v_d, v_q, ...);
    
    // 把占空比写入 PWM 接口积木，电机就转了！
    ctl_set_pwm_channel_duty(&pwm_u, svpwm.output.u);
}
```

## 4. 学习建议

1.  **先看 `intrinsic`**: 虽然它看起来很基础，但 PID 是万物之源。试着看懂 `pid.c`，理解它是怎么把误差变成输出的。
2.  **善用 `hardware_preset`**: 不要在一开始就纠结参数怎么测，先用预设参数让电机转起来，建立信心。
3.  **阅读 `COMPONENT_GUIDE.md`**: 这份文档比我讲的更详细，当你对某个具体模块（比如“SVPWM到底要传什么参数”）有疑问时，它是最好的字典。

祝你在电机控制的学习之路上玩得开心！如果代码跑不通，多半是接线或者参数设错了，别灰心，Debug 也是搭积木的一部分。
